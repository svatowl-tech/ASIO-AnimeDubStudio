# DubStudio Pro 🎙️

**Озвучивайте аниме, кино, манхву, комиксы, игры и аудиокниги в одной программе — без переключения между пятью окнами.**

Если вы когда-нибудь записывали озвучку, вы знаете эту боль: в одном окне — DAW, во втором — плеер с видео или страница манхвы, в третьем — таблица с репликами и правками от куратора, а потом ещё вручную переименовывать десятки файлов и искать, какую фразу случайно пропустили.

**DubStudio Pro** собирает весь рабочий процесс актёра озвучивания, диктора и фандаб-студии в одном быстром, лёгком и полностью автономном приложении. Бесплатно, без подписок, без облачных аккаунтов — все ваши проекты и записи хранятся прямо у вас на диске.

---

## 🎯 Почему стоит попробовать DubStudio Pro

- **Всё под рукой на одном экране** — видеоплеер или ридер комикса/манхвы, список реплик по ролям, многодорожечный таймлайн и запись голоса синхронизированы друг с другом.
- **Ни одной забытой реплики** — программа сама считает прогресс записи, подсвечивает пропущенные фразы и одной кнопкой переводит к следующему незаписанному фрагменту.
- **Готово к кастингам и пробам за пару кликов** — записывайте пробы на разных персонажей на отдельные дорожки, а ваш ник даббера автоматически подставится в имена экспортируемых файлов.
- **Мгновенный отклик и чистый звук** — нативный аудиодвижок на Rust с низкой задержкой, калибровкой оборудования, шумоподавлением (Noise Gate), лимитером от перегрузок на криках и нормализацией при экспорте.
- **Работает на любой раскладке клавиатуры** — горячие клавиши срабатывают одинаково чётко на русской и английской раскладке.

## 🔥 Что умеет программа

### 🎬 Дубляж и фандаб (аниме, сериалы, фильмы)
- **Синхронный видеоплеер и аудиореференс** — открывайте `.mp4`, `.mkv`, `.webm`, `.mov`, `.avi` и другие форматы, извлекайте оригинальную дорожку через встроенный FFmpeg.
- **Умная работа с субтитрами и сценариями** — импорт `.ass`, `.srt`, `.vtt`, `.csv`, `.txt`, `.docx` с автоматической разбивкой по персонажам и таймингам.
- **Контроль пропусков** — индикатор прогресса по ролям, переход к следующей незаписанной реплике с учётом преролла и предупреждение перед экспортом, если что-то осталось без озвучки.
- **Импорт фиксов от куратора** — вставьте список правок текстом, чтобы быстро перезаписать нужные фразы.
- **Готовое видео с озвучкой** — вшивайте записанную дорожку прямо в видеофайл (Video Muxing) без потери качества картинки.

### 📖 Режим комиксов, манхвы, вебтунов и ранобэ
Идеально для озвучки комиксов, вебтунов и прохождения кастингов по манхве:
- **Прямая загрузка глав с сайтов семейства Lib** — вставьте ссылку с **MangaLib**, **RanobeLib**, **SlashLib** или **HentaiLib**, выберите нужный диапазон глав (например, `1–5` для проб) и переводчика — главы сохранятся прямо в папку проекта.
- **Поддержка локальных файлов** — открывайте **`.cbz`**, **`.cbr`** (RAR4/RAR5), **`.fb2`** (включая `.fb2.zip`, UTF-8 и Windows-1251, с обложками и иллюстрациями), **`.pdf`** и **`.epub`**. Архивы `.cbz` и `.cbr` можно просто перетащить в окно программы.
- **Два режима чтения** — непрерывная **лента манхвы (вебтун)** или **постраничный просмотр** с удобной навигацией по главам и миниатюрам страниц.
- **Привязка записи прямо к облачкам диалогов** — ставьте пины-метки прямо на репликах на странице. При клике по записанной фразе или перемещении по таймлайну ридер автоматически прокрутит нужную главу точно к тому месту, где звучала реплика.
- **Раздельные дорожки для разных персонажей** — метки и автопереходы привязываются к активной дорожке, поэтому при записи проб на нескольких героев переходы с одной дорожки не мешают другой. Есть и кнопка быстрой очистки таймлайна с сохранением загруженного комикса в проекте.

### 🎮 Игровая озвучка, кастинги и аудиокниги
- **Импорт игровой озвучки** — загружайте папку исходных реплик вместе с TXT-переводом и записывайте дубли с пакетной выгрузкой.
- **Режим кастинга** — быстрый старт проб по аудио/видео с текстом или субтитрами.
- **Аудиокниги и дикторская работа** — импорт книг и документов (`.docx`, `.fb2`, `.epub`, `.pdf`, `.txt`), встроенный телепромптер (суфлёр) и экспорт всех реплик единым файлом с ровными паузами (`1.0с` или `1.5с`).
- **Backstage Mode** — параллельная запись видео с веб-камеры и голоса для бэкстейджей, шортсов и рилсов + встроенный редактор бэкстейджа.

### ✂️ Удобный монтаж и гибкий экспорт
- **Всё нужное на таймлайне** — нарезка (Split), сдвиг, режим Ripple Edit, копирование/вставка фрагментов, полная история отмены и повтора (Undo / Redo).
- **Любой формат на выходе**:
  - **WAV** (`24-bit / 48 kHz`), **MP3** (`320 kbps`), **FLAC** (`Lossless`) с нормализацией громкости.
  - **Стемы по дорожкам** или единый **ZIP-архив со всеми стемами**.
  - **Пакетный экспорт** отдельных реплик и **муксинг в видео**.
- **Портативные проекты `.dub`** — проект, записи, субтитры и загруженные страницы комикса аккуратно лежат в одной папке и открываются двойным кликом.

## ⚡ Быстрый старт

### 1. Скачайте приложение
Перейдите в раздел **Releases** репозитория и скачайте установщик для вашей системы:
- **Windows:** `.exe` (установщик) или `.msi`
- **macOS:** `.dmg` (Universal — работает и на Apple Silicon M1–M4, и на Intel)
- **Linux:** `.AppImage` или `.deb`

### 2. Начните озвучку за 3 шага
1. Нажмите **«Импорт»** в верхней панели и выберите ваш материал — видео с субтитрами, комикс/манхву (ссылку с Lib или файл `.cbz` / `.cbr` / `.fb2` / `.pdf` / `.epub`), документ или кастинг.
2. Укажите свой **ник даббера** в шапке и при необходимости пройдите быструю калибровку задержки микрофона в настройках.
3. Нажмите **`R`** для записи, **`Space`** для прослушивания и **«Экспорт»** — готовый файл с нормализацией сразу можно отправлять режиссёру или в тему с пробами.

## 🎹 Основные горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `Space` | Воспроизведение / Пауза |
| `R` | Начать / Остановить запись |
| `S` | Разрезать фрагмент по курсору (Split) |
| `Delete` / `Backspace` | Удалить выделенные фрагменты |
| `Ctrl + Z` / `Ctrl + Shift + Z` | Отменить / Повторить действие |
| `←` / `→` | Перейти к предыдущей / следующей реплике |
| `Esc` | Отменить текущую запись |

*Все горячие клавиши можно переназначить под свои привычки в настройках приложения.*

## 🛠 Для разработчиков и сборки из исходников

<details>
<summary>Развернуть инструкцию по локальной сборке и стек технологий</summary>

### Требования
- **Node.js** 18+ и **npm** 9+
- **Rust (`stable`)** для сборки десктопного приложения Tauri

### Установка и запуск
```bash
git clone https://github.com/your-username/dubstudio-pro.git
cd dubstudio-pro

# Установка зависимостей (автоматически подтянет бинарники FFmpeg)
npm install

# Запуск веб-версии (порт 3000)
npm run dev

# Запуск десктопного приложения (Windows / macOS / Linux)
npm run tauri dev
```

### Проверка и сборка релиза
```bash
npm run lint
npm run build

# Локальная сборка установщика под текущую ОС
npm run version:sync
npm run tauri build
```

В проект также встроен workflow **GitHub Actions** (`.github/workflows/release.yml`), который при обновлении версии и пуше автоматически собирает релизы для Windows (`.exe`, `.msi`), macOS Universal (`.dmg`) и Linux (`.AppImage`, `.deb`).

### Стек технологий
- **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS 4, Zustand, Framer Motion
- **Desktop Core:** Tauri 2 (Rust)
- **Audio & Media:** Rust Audio (`cpal`, `hound`, `rubato`, `ebur128`), Web Audio API, FFmpeg / FFprobe
- **Документы и комиксы:** нативные Rust-парсеры (`zip`, `quick-xml`, `lopdf`), `pdfjs-dist`, `jszip`, `node-unrar-js` (WASM RAR4/RAR5), `ass-compiler`

</details>
