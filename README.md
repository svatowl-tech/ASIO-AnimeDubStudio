# DubStudio Pro 🎙️

**DubStudio Pro** — это профессиональная кроссплатформенная цифровая звуковая рабочая станция (DAW) и специализированный софт для дубляжа, закадрового озвучивания, фандаба (аниме, сериалы, фильмы, видеоигры), локализации медиаконтента, работы дикторов и создания аудиокниг.

Приложение объединяет в одном интерфейсе многодорожечную аудиозапись с минимальной задержкой, синхронный видеоплеер, умный суфлер (телепромптер), интеллектуальный авто-парсинг сценариев и субтитров, визуальный отслеживатель незаписанных реплик и AI-ассистента для адаптации текста.

## 📌 Назначение приложения

DubStudio Pro создано с учетом реальных потребностей актеров озвучивания, дикторов, укладчиков текста и звукорежиссеров:
- **Озвучивание аниме и дорам:** удобная разбивка диалогов по ролям, поддержка форматированных субтитров `.ass` / `.srt`.
- **Дубляж фильмов и видеоигр:** точный липсинк, наглядная визуализация волны, калибровка задержки и быстрый сплит/сдвиг сегментов.
- **Работа дикторов и аудиокниги:** чтение текста с интерактивного суфлера, запись дублей в режиме реального времени.
- **Создание бэкстейдж-контента:** параллельная запись видео с веб-камеры и микрофона (Backstage Mode).

## ✨ Ключевые возможности

### 🎧 1. Многодорожечная запись и Аудио-движок
- **Нативный Rust Audio Engine (`cpal`):** ультранизкая задержка ввода/вывода, прямой доступ к звуковым устройствам OS.
- **Входная аудиообработка в реальном времени:**
  - **Noise Gate (Шумоподавитель):** отсекает фоновый шум микрофона и дыхание в паузах.
  - **Peak Limiter (Лимитер):** защищает от клиппинга и перегрузок на громких эмоциях и криках.
- **Калибровка задержки (Latency Compensation):** встроенный мастер измерения и компенсации задержки оборудования.
- **Backstage / Parallel Mode:** одновременная запись голоса и видео с веб-камеры для блогеров и бэкстейджей.

### 🎬 2. Работа со Сценарием, Ролями и Субтитрами
- **Универсальный импорт:** `.txt`, `.docx` (Microsoft Word), `.epub`, `.fb2`, `.pdf`, `.ass` (Advanced SubStation Alpha), `.srt`.
- **Авто-парсинг:** автоматическое выявление персонажей, ролей и таймингов.
- **Smart Script Sync:** плавное авто-центрирование активной реплики без лишней тряски интерфейса (авто-скролл срабатывает только при выходе реплики за пределы 60% комфортной зоны экрана).
- **Индикатор покрытия и поиск пропущенных реплик:**
  - Прогресс-бар: *"Записано X из Y (Осталось Z)"*.
  - Кнопка **«Записать след. пропуск»** мгновенно перемещает плейхед к ближайшей незаписанной фразе с учетом преролла.
  - Пульсирующая янтарная подсветка незаписанных реплик на сценарии и таймлайне.
  - Предупреждающий диалог перед экспортом, если выбранные роли записаны не полностью.
- **Smart Teleprompter:** интерактивный суфлер с гибкой настройкой размера шрифта, межстрочного интервала, авто-пасинга и зеркального отображения.

### ✂️ 3. Редактирование и Таймлайн
- **Режим Ripple Edit:** автоматический сдвиг последующих сегментов при обрезке или удалении.
- **Инструменты монтажа:** точный сплит (Split), склейка (Join), дублирование, вырезание/копирование/вставка (Ctrl+C / Ctrl+V).
- **Поддержка любых языковых раскладок:** горячие клавиши корректно работают как на английской, так и на русской раскладке клавиатуры.

### 🤖 4. AI-Ассистент (Google Gemini)
- Автоматический перевод диалогов с сохранением эмоций.
- Адаптация длин реплик под оригинальный тайминг (липсинк).
- Разделение сложных реплик и генерация описаний проекта.

### 🎛️ 5. Сведение, Мультимедиа и Экспорт
- **Встроенные DSP-эффекты:** эквалайзеры, компрессоры, деэссеры, реверберация для каждой дорожки.
- **Интеграция FFmpeg:** извлечение оригинального аудио из видеофайла.
- **Замена аудио в видео (Video Muxing):** вшивание готовой озвучки прямо в видео без перекодирования видеопотока.
- **Экспорт Stems:** выгрузка каждой дорожки отдельно или общего финального микса в форматы `WAV`, `MP3`, `AAC`, `FLAC`, `WMA`.

## 🤖 Автоматическая сборка и релизы на GitHub (CI/CD)

В проект встроен автоматический рабочий процесс **GitHub Actions** (`.github/workflows/release.yml`), который при каждом коммите или изменении версии автоматически собирает готовые установочные файлы под все популярные платформы.

### Как происходит создание релиза:
1. Вы вносите изменения и обновляете версию в `package.json` (например, `1.2.0`).
2. Запускаете команду синхронизации или делаете коммит:
   ```bash
   npm run version:sync
   git commit -am "bump version to 1.2.0"
   git push origin main
   ```
3. GitHub Actions автоматически:
   - Синхронизирует версии в `package.json`, `tauri.conf.json` и `Cargo.toml`.
   - Создает тег `v1.2.0` на GitHub.
   - Подготавливает иконки для всех платформ (`.ico` для Windows, `.icns` для macOS, `.png` для Linux).
   - Подтягивает необходимые библиотеки бинарников FFmpeg (`ffmpeg-static`, `ffprobe-static`).
   - Собирает бинарные файлы:
     - **Windows:** `.exe` (NSIS-установщик) и `.msi`
     - **macOS:** `.dmg` и `.app` (Universal Binary для M1/M2/M3/M4 Apple Silicon и Intel)
     - **Linux:** `.AppImage` и `.deb`
   - Публикует готовый релиз с дистрибутивами в разделе **GitHub Releases**.

## 🚀 Локальная разработка и сборка

### Требования к системе
- **Node.js:** v18 или новее
- **NPM:** v9+
- **Rust Toolchain:** `stable` (для сборки нативного движка Tauri)

### Установка зависимостей
```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/dubstudio-pro.git
cd dubstudio-pro

# Установите зависимости (автоматически настроит FFmpeg бинарники)
npm install
```

### Запуск в режиме разработки
```bash
# Веб-версия в браузере
npm run dev

# Десктопное приложение Tauri (Windows / macOS / Linux)
npm run tauri dev
```

### Сборка десктопного приложения локально
```bash
# Синхронизация версий конфигурационных файлов
npm run version:sync

# Сборка установочного пакета под вашу текущую ОС
npm run tauri build
```

## 🎹 Основные Горячие Клавиши (Hotkeys)

| Клавиша | Действие |
| :--- | :--- |
| `Space` | Воспроизведение / Пауза |
| `R` | Старт / Остановка записи |
| `S` | Разрезать сегмент в точке плейхеда (Split) |
| `Delete` / `Backspace` | Удалить выделенный сегмент |
| `Ctrl + Z` / `Ctrl + Shift + Z` | Отмена / Повтор действия (Undo / Redo) |
| `Left Arrow` / `Right Arrow` | Перемещение к предыдущей / следующей реплике |
| `Esc` | Сбросить / Отменить текущую запись |

*Все горячие клавиши подлежат гибкой кастомизации в настройках приложения.*

## 🛠 Технологический стек

- **Frontend:** React 19, TypeScript, Vite 8
- **Styling:** Tailwind CSS 4, Framer Motion
- **Desktop Core:** Tauri 2.11 (Rust Engine)
- **Audio Processing:** Native Rust Audio (`cpal`, `hound`, `rubato`, `ebur128`) + Web Audio API
- **Media Engine:** FFmpeg (`ffmpeg-static`, `ffprobe-static`)
- **AI Engine:** Google Gemini SDK (`@google/genai`)
- **Document Parsing:** PDF.js, Epub.js, Mammoth (Docx), ASS Compiler
